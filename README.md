# askender/homebrew-tap

Personal Homebrew tap.

```sh
brew tap askender/tap
brew install fansctl
```

- [fansctl](https://github.com/askender/fansctl) — macOS fan control & power
  survey for Apple Silicon: one dependency-free binary, menu bar app + CLI
  (smart curve, PI thermostat, power survey). Formula builds from the
  release source tag.
